No CI runner, no build server, no deploy key. The git remote is itself a canister: it took the push, read the artifact out of the commit, and installed it into the canister you are reading this from.

How this page got here

  1. git pushA stock git client pushes to {{GIT_ORIGIN}}/{{REPO}}.git over smart-HTTP.
  2. ic-git ingests the packObjects and refs land in the canister's stable memory. The push enqueues a deploy job.
  3. The queue reads the commitIt resolves app.wasm in the pushed commit's tree and validates the module.
  4. install_codeic-git calls the management canister and installs that wasm into {{CANISTER}} — this canister.

The commit this came from

Read from ic-git's deploy log, not from the branch tip: the log records each install and the canister it went into, so a push that is still queued, held for votes, or failed does not get credited here.
